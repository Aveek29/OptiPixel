How It Works

1

Upload

Drag and drop or select a JPG, PNG, or WebP image. Max 10MB / 4 megapixels.

2

Analyze

OpenCV reads sharpness, brightness, contrast, and resolution. The system picks the best enhancement profile automatically.

3

Enhance

Real-ESRGAN AI model runs super-resolution. Tiled inference on CPU. 2x upscale with detail reconstruction.

4

Download

Get your enhanced image instantly. Files are temporary and cleared on server restart.

Enhancement Profiles

LIGHT

CLAHE contrast correction + sharpening. Same resolution. Fast (~1-2s).

SUPER_RES

Real-ESRGAN 2x upscaling with detail reconstruction. 30s-2min on CPU.

RESTORE

Noise reduction + Real-ESRGAN super-resolution. For noisy/low-quality input.

Performance & Requirements

CPU Inference

Real-ESRGAN runs on CPU (no GPU required). Tiled processing keeps memory under 2GB.

Processing Time

  • LIGHT profile: ~1-2 seconds
  • SUPER_RES 2x: 30s - 2min (CPU)
  • RESTORE: 45s - 2min (CPU)

Limits

  • Max upload: 10MB
  • Max resolution: 4 megapixels
  • Timeout: 3 minutes
  • Scale: 2x (locked for CPU)

Memory

  • Model: ~65MB weights
  • Inference: ~1.5GB RAM
  • Tiled: 256px tiles

Privacy & Data

Temporary Storage

Uploaded and enhanced images are stored temporarily on the server's local disk. Files are not persisted — they are removed on server restart or redeploy.

No Permanent Retention

No cloud storage is used. Images are processed in memory and served back to you directly. Nothing is shared or made public.

No Signup Required

No accounts, no tracking, no cookies. Just upload, enhance, and download.
